# 인권중심 중재기술 (QualityRights 훈련도구 앱)

세계보건기구 **퀄리티라이츠(QualityRights)** 에 기반한 *치료친화적 환경조성을 위한
인권중심 중재기술* 5종의 인쇄 매뉴얼을, 교육·토론 현장에서 바로 활용할 수 있도록
디지털화한 **iOS/iPadOS 앱 모음**입니다.

> 이 앱들은 임상·교육의 보조 도구이며, 전문적 훈련·수퍼비전을 대체하지 않습니다.
> 입력한 토론·성찰 답변은 모두 기기에만 저장되고 외부로 전송되지 않습니다.

## 5개의 앱 (도구별 독립 앱)

각 도구는 **독립 실행 앱**으로 만들어졌으며, 모든 앱은 공통으로 **도입 가이드라인**
(인권중심 중재기술의 철학·도입 전략·교육 단계)을 함께 담고 있습니다.

| 앱 | 도구 | 대표저자 · 기관 | 테마색 |
|----|------|----------------|--------|
| `OpenDialogue` | 오픈 다이얼로그 (지역사회 네트워크 미팅) | 한국 오픈 다이얼로그 학회 | 블루 |
| `DOTP` | 병원기반 네트워크 미팅 (DOTP) | 정성권 · 이음병원 | 틸 |
| `Stabilization` | 흥분환자 안정화치료 (고조완화기법) | 이요한 · 천주의성요한병원 | 앰버 |
| `Recovery` | 회복·퇴원계획 (퀄리티라이츠 리커버리) | 조용혁 · 아주대·수원시성인정신건강복지센터 | 그린 |
| `SupportedDecision` | 동료지원 지원의사결정 | 하경희 · 아주대 공공정책대학원 | 바이올렛 |

각 앱은 **훈련도구 · 자원 · 정보** 세 개의 탭으로 구성됩니다.

- **훈련도구** — 도입 가이드라인 + 해당 도구의 장(章)별 교육 내용과 토론·성찰 질문
- **자원** — 5종 도구의 교육 문의처, 위기·인권 상담 전화(원터치 연결)
- **정보** — 퀄리티라이츠 소개, 원저작자 표시(출처), 입력 내용 전체 초기화

## 상호작용 요소

인쇄 매뉴얼의 문항 유형을 그대로 구현했습니다.

- 자유 서술형 토론·성찰 질문 (자동 저장)
- 체크리스트 · 1–10 / 0–100 척도 슬라이더 · 표 형식 입력
- 교육용 정의 카드, 예시/사례 카드, 그리고 실제 회기의 **축어(verbatim) 대화 예시**

## 기술 스택

- SwiftUI (iOS 16+), 외부 의존성 없음
- `ObservableObject` 상태 관리 + `UserDefaults` 영속화 (오프라인·프라이버시 우선)
- Xcode 16의 *file-system synchronized group* 프로젝트 형식

## 웹앱 (브라우저 버전)

5종 도구 + 도입 가이드라인을 **하나의 브라우저 웹앱**으로도 제공합니다. 설치 없이
링크만으로 열람·작성할 수 있고, 입력한 토론·성찰 답변은 각 브라우저에 로컬 저장됩니다.

```
web/
├─ index.html      단일 페이지 웹앱 (반응형 · 라이트/다크 · 로컬 자동저장)
└─ content.js      5종 도구 + 가이드라인 콘텐츠 데이터
```

- **바로 보기**: `web/index.html`을 브라우저로 열면 됩니다.
- **GitHub Pages 배포**: 저장소 Settings → Pages에서 이 브랜치의 `/web` 폴더를
  소스로 지정하면 공개 URL로 호스팅됩니다.
- **콘텐츠 재생성**: iOS 앱과 동일한 `src/` 콘텐츠로부터 자동 변환됩니다.
  ```bash
  python3 tools/web-content.py src > web/content.js
  ```

## 저장소 구조

```
qualityrights/
├─ src/                         공통 소스(단일 원본)
│  ├─ engine/                   앱 공통 엔진 (Model·Store·Theme·Views·공통 Content)
│  └─ tools/                    도구별 콘텐츠 5종 + 도입 가이드라인
├─ tools/
│  ├─ scaffold.sh              src/ 로부터 5개 iOS 앱을 생성/동기화
│  ├─ web-content.py           src/ 로부터 웹앱 콘텐츠(content.js) 생성
│  └─ project.pbxproj.tmpl     Xcode 프로젝트 템플릿
├─ apps/                        생성된 5개의 독립 Xcode 앱 (열어서 바로 빌드)
│  └─ OpenDialogue/ · DOTP/ · Stabilization/ · Recovery/ · SupportedDecision/
└─ web/                         브라우저 웹앱 (index.html + content.js)
```

앱 코드는 **손으로 중복 관리하지 않습니다.** 공통 엔진과 도구 콘텐츠는 `src/`에
한 벌만 두고, `tools/scaffold.sh`가 이를 각 앱 폴더로 복사해 5개의 독립 앱을
생성합니다.

## 빌드 방법

1. macOS + **Xcode 16 이상**에서 원하는 앱의 `.xcodeproj`를 엽니다.
   (예: `apps/OpenDialogue/OpenDialogue.xcodeproj`)
2. 서명 팀(Signing & Capabilities → Team)을 본인 계정으로 설정합니다.
3. 시뮬레이터 또는 기기를 선택하고 실행(⌘R)합니다.

## 콘텐츠 수정 후 재생성

콘텐츠나 엔진을 수정할 때는 `src/`의 파일만 고친 뒤 스크립트를 다시 실행합니다.

```bash
tools/scaffold.sh
```

> `apps/` 폴더의 파일은 스크립트가 생성하는 산출물이므로 직접 수정하지 마세요.
